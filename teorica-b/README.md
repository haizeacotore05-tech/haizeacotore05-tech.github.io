# Teórica Permiso B

App de estudio para el examen teórico del permiso B (DGT): 14 temas con apuntes y trucos, galería de señales dibujadas, tests con la explicación de cada opción, simulacro de 30 preguntas y tarjetas de memoria.

Se instala como app desde el navegador («Añadir a pantalla de inicio») y funciona sin conexión. El progreso se guarda en el propio dispositivo.

Basada en los intensivos de Autoescuela Mikel. Comprueba siempre los datos con los tests oficiales de la DGT.
